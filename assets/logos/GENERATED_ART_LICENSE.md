# Generated artwork license

To the extent possible under law, the contributors to this project dedicate
the original artwork listed below to the public domain under the
[CC0 1.0 Universal dedication](https://creativecommons.org/publicdomain/zero/1.0/):

- `generated/category-*.png`
- `generated/category-*.svg`

The SVG files are the editable, background-free vector masters. The matching
PNG files are transparent compatibility renders for IPTV clients.

The v3 artwork uses only the neutral `#F7F8FA` fill and `#1B2230` outline,
with rounded joins and no gradients, shadows, visual text, or background cards.

This dedication does not cover files under `people/`. Those are third-party
portraits with their own license and attribution recorded in
`ATTRIBUTION.md` and `icon_catalog.csv`.
